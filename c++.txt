5. (Two's complement)- Its a Data Structure and Algorithms concept where it itself is an algorithm of storing the negative nums.
                        It mainly is a computer architecture/Binary representation concept for Binary value representation. This 
                        is used for representing the negative numbers efficiently in the computer memory.
                (Steps of negative value binary conversion)-
                    1. First the value is converted to the Binary form.
                    2. Second, the prefix(0 or 1) is added infront of the Binary form of the value. (0) represents "Positive value" 
                            and (1) represents the "Negative value". This prefix is the most imprtant digit of any Binary form value.
                            Because it represents the "Sign of the value". The prefix that we add that represents the sign, is also known 
                            as the (MSB- Most Significant Bit).
                    3. Third, we find the "One's Comeplement"(the flipping of the values, 0 becomes 1 amd 1 becomes 0). 
                    4. Fourth, we do (+1) at the one's complemented binary form value. 
                The Final form after allt these 4 steps gives us the Negative Binary representation. This process of conversion from decimal to 
                binary or binary to decimal for negative numbers is knwon as the "Two's complement".

                    (Bitwise NOT; ~)
                    (Butwise right-shift; >>)- It shifts every individual bits of a Binary at the right side by (n) places. The lower digits are

                    (Bitwise left-shift; <<)- It shifts every individual bits of a Binary at the left side by (n) places.

10. [Algorithms and algorithmic techniques/patterns]-
        These are the methods which we we can use for solving a question or a type of question, based on a Data Structure, and also
        use them for manupulating the Data Structure. Given here the generally used and well-known algorithms that are used in DSA-

        (Linear Search)- This algorithm is used for searching for a target in an array or vector by going and checking the digits one 
                            by one. In this, we use a single loop for the target checking.
        (2-Pointer Approach)- This is used for finding a data by using 2 positions(pointers) for finding a data or target,instead of 
                                using nested loops.
        (Kadane's Algorithm)- It is an efficient algorithm used to find the maximum sum of a contiguous subarray within a 
                                one-dimensional array of numbers. Its mainly used for array or vector type data structure.
                                This algorithm uses 2 positions, (current_sum) and (max_sum). we iterate over the vector array with a single 
                                loop. We compare the current_sum and the previous sum(max_sum), if we get the current_sum < 0 then we initialize 
                                it to 0. Where the main motive is to prevent negative ints from being the max_sum. At first we take the current_sum = 0 and 
                                the max_sum = INT16_MIN.(negative infinity). Here the single loop iteration is the Linear search method of iteration.
                                Its a type Dynamic Programming Algorithm.
	(Sliding Window)- Its not a specific form of algorithm but its an algorithmic technique/pattern. Its mainly used for Arrays
				related problems. In this, we slide/hover/iterate over the various subarrays of the main_array, and 
				perform desired functions/operations. We iterate over the respective array while keeping the desired
				information updated. This optimisation method could be used for problems related to "contiguous 
				subarrays" and "sub_strings".
					Its uses nested loops, thus it have greater time_complexity like O(n^2). 

    (Moore's Voting Algorithm)- This is an efficient algorithm which we use to find the "Majority" element in an array(of occurent
                                    range n/2 times). The alorithm maintains a candidate(ans) and count(frequency). 
                                        If the current element matches the (candidate) then (counts) would be incremented and if not 
                                    then (counts) would be decremented. 
                                    After one complete traversel, if the (counts > 0) then the remaining (candidate) is the potntial 
                                    Majority Element of the array. But if (counts == 0) then there is no Majority Element.
                                The algorithm runs with O(n) time complexity and O(1) space complexity.

12. [Time and Space complexity]-
        *Note: Time complexity is not the time taken to execute the code or programme. Time complexity is a completely different
                concept. It is also to be notted that different machines like, windows, mac, Linux or even different platforms like 
                LeetCode, CodeForces etc, -may take different programme execution time.

        (Time Complexity)- Time complexity is a way to measure how the running time of an algorithm grows as the input size (n) 
                            increases. It is usually expressed using Big O notation, which describes the worst-case growth rate.
                            Its the number of operations performed where each operation is the size of (n).
                        Time complexity is mainly depended on 2 things-
                            1. Amount and size of the input(s).
                            2. Number of operations performed on the input.
                        Here (input) means the place holders/variables that are present in the code. 
                *For the Time complexity of different algorithms, the worst-case scenerioes are kept in mind.
                *The big-O-> O() tells us the time complexity in the worst case scenerio.
                *The time complexity like- O(n), O(n^2), O(n^3) etc, are forms of Functions.
                    Some functions are Polynomialic- O(n) = n
                                                     O(n^2) = n^2 + n
                                                     O(n^3) = n^3 + n^2 + n
                                                     O(n^4) = n^4 + n^3 + n^2 + n
                                                     O(n^k) = n^k + n^(k-1) + n^(k-2) + ... + n^2 + n
                                            There the term with the highest degree represents the worst-case scenerio and its only 
                                            the Time Complexity of the algorithm/code.
                                    *Note: The constants of the Function must be ignored and the variable (n) must be focused. The 
                                                The constants represents the number of times a certain operation is being perunit of
                                                input(n).
                *There 3 different kinds of time-complexity notations-
                    (Big O notation)- Represented in the form of O(). It denotes the time complexity in the worst case scenerio. Its also 
                                        known as the Upper Bound case.
                    (Theta-θ notation)- Represenetd in the form of θ(). It denotes the time complexity in the average case scentio.
                    (Omega-Ω notation)- Represented in the form of Ω(). It denotes the time complexity in the best case scenrio. It also 
                                        known as the Lower Bound case.

        (Space Complexity)- Its the amount of space taken by an algorithm as function of input size(n). 
                                In the code- there are 2 forms of space- 
                                    1. Actual input of all the place holders like arrays, vectors, string etc, and the variables.
                                    2. Auxiliary Space.(Extra space; calculated as Space complexity).
                *It must be noted that the auxiliary space is the main aspect for calculating the Space complexity.
                *The input-size and space complexity are directly proportional and as well as the time-complexity.
